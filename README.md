# JARVIS-X

A Multimodal Autonomous Personal AI Agent with Long-Term Memory, Tool Use, Vision and Proactive Intelligence.

## Project Goal

JARVIS-X aims to develop a personal AI assistant capable of understanding natural language, maintaining long-term memory, using tools, processing multimodal information, planning tasks, monitoring approved information sources, and providing proactive assistance.
